## 旅行经费工作台 v1.0.8

在 AI 行程规划基础上增强，并支持把分享页保存成图片（向后兼容 v1.0.7 数据，无需迁移）。

### 新功能
- **AI 行程调整（对话式）**：生成或填写行程后，路线编辑页「景点路线」旁出现「调整」按钮，打开对话面板用日常语言提出改动（如「把第二天换成塔尔寺」「第一天太赶了精简一下」），AI 基于当前行程给出改好的完整版本；支持多轮连续调整，满意后一键「应用此版本」回填到「景点路线」。
- **分享页导出图片**：只读分享页新增「导出为图片」按钮，一键把行程卡片保存为高清图片，方便发群、发朋友圈或存档。导出在浏览器本地完成，不会上传你的行程内容。
- **AI 接入更省心**：AI 配置新增「跳过 SSL 证书验证」开关，内网或自签名证书（如 NAS 自建服务）也能正常接入；接口连不通时会给出明确原因提示；慢速模型也能跑完（等待时间放宽到 120s）。

### 权限与安全
- AI 功能由管理员按账号开启，未开启的账号看不到「AI 规划 / 调整」按钮，避免误用。
- 分享页内容服务端转义，防 XSS；密钥不在前端暴露（读取时掩码）。
- 分享页独立 CSP（允许内联脚本以支持导出），主应用 CSP 仍保持「仅同源脚本」。

### 升级方式
- 群晖 / Docker：`docker compose pull && docker compose up -d`（镜像 `ghcr.io/kyson-666/travel-expense:v1.0.8` 或 `kyson666/travel-expense:v1.0.8`）。
- 安卓客户端：`app-debug.apk` 随本 Release 发布，内置服务器地址，安装即用。
