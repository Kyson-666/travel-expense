# 旅行经费工作台 v1.0.6

## 这次更新了什么

- **统计趋势图更好用**：工作台里的「逐年花费趋势」现在按年份展示；当你在筛选里选定某一年时，图表会自动切换成那一年每个月的花费趋势，数据随筛选条件实时变化。
- **修复「隐藏系统示例」**：勾选后，示例路线以及对应的统计数字会在路线列表和图表里一起隐藏。之前管理员账号下示例路线无法被隐藏，现已正常。
- **代码整理**：把重复出现的币种符号、日期解析、操作日志等逻辑合并成统一实现，便于后续维护；前端统计改为直接调用服务端接口，数据口径与后台全部记录保持一致。
- **补了自动化测试**：新增回归用例覆盖上面的趋势切换和隐藏示例行为，避免以后再出现同样的问题。

## 怎么升级

拉取新镜像并重启容器即可，数据文件（SQLite）保持不变，无需迁移。

镜像已发布到两个仓库，均包含 amd64 与 arm64 两种架构：

- GitHub Container Registry：`ghcr.io/kyson-666/travel-expense:v1.0.6`（同时带 `latest` 标签）
- Docker Hub：`kyson666/travel-expense:v1.0.6`（同时带 `latest` 标签）

## 验证情况

前端语法检查与完整测试套件（共 6 个脚本、87 项用例）全部通过。
