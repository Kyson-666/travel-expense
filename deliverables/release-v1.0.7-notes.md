# 旅行经费工作台 v1.0.7

自托管旅行路线 + 经费管理全栈单镜像，新增 AI 行程规划能力并发布安卓客户端。

## 新增

- **AI 行程规划**：管理后台新增「AI 配置」页，填写 AI 接口（地址 / 密钥 / 模型）并一键测试连通性；管理员为指定账号开启后，路线编辑页「景点路线」旁出现「AI 规划」按钮，填好起止日期与目的地即可一键生成按天行程草稿（上午 / 下午 / 晚上 + 住宿城市），可手动采纳或改写。
- **出行日期结构化**：路线出行日期由单一文本改为「开始 / 结束」双日期输入，自动计算天数；旧路线文本日期自动兼容解析（向后兼容 v1.0.6 数据，无需迁移）。
- **权限可控**：AI 功能由管理员按账号开启，未开启的账号看不到「AI 规划」按钮，避免误用。
- **AI 接入更省心**：AI 配置新增「跳过 SSL 证书验证」开关，内网或自签名证书（如 NAS 自建服务）也能正常接入；接口连不通时会给出明确原因提示；生成行程的等待时间放宽，慢速模型也能出结果。
- **安卓客户端**：Release 附件 `app-debug.apk`，内置服务器地址，手机安装即用（下载与安装见 Wiki「安卓客户端-APK下载」）。

## 镜像

- GitHub Container Registry：`ghcr.io/kyson-666/travel-expense:v1.0.7`（或 `:latest`）
- Docker Hub：`kyson666/travel-expense:v1.0.7`（或 `:latest`）
- 双架构 linux/amd64 + arm64，推送 `v*.*.*` tag 由 GitHub Actions 自动构建发布。

## 升级

`docker compose pull && docker compose up -d` 即可；数据卷沿用旧 `app.db`，无需迁移。
